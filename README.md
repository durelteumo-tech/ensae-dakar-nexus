# ENSAE Hub

Plateforme collaborative conçue pour les étudiants de l'ENSAE Dakar (AS1 à AS3, ISE1 à ISE3). Elle réunit dans un même espace les cours, les échanges de groupe, la recherche de binômes et des outils de révision assistés par IA.

## Ce que propose l'application

- **Accueil** : tableau de bord personnel avec vos activités récentes et des accès rapides vers chaque espace.
- **Ressources** : bibliothèque partagée pour publier et télécharger des supports de cours, annales et scripts (PDF, R, Python, Stata).
- **Projets & Salons** : messagerie de groupe en temps réel (citations de messages, émojis, mode plein écran) accompagnée d'un tableau de suivi des tâches.
- **Réseau & Matchmaking** : annuaire étudiant pour présenter son profil, trouver un binôme de projet ou de mémoire et le contacter directement sur WhatsApp ou Discord.
- **Studio IA** : génération de QCM d'entraînement, de fiches de synthèse et de résumés à partir de sujets ou de documents.

## Lancer le projet en local

1. Installer les dépendances :
   ```bash
   npm install
   ```
2. Démarrer l'application :
   ```bash
   npm run dev
   ```
3. Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.
